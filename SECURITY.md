# Security

## If you find a problem

Please do not open an issue: it is public. Use **Report a vulnerability** in the
[Security](https://github.com/peppeg/vedetta/security) page of this repository: only the
author sees it.

Say what happens, how to make it happen, and which version you have (**Settings → About**).
Leave out keys, codes and other people's data.

Vedetta is made by one person, in their spare time. You will get an answer, not always a
quick one. Only the latest version is corrected.

## What to expect

Vedetta is meant for a home network, not for the open internet. Who can reach it, what it
protects from and what it does not are in [Security](guide/security.md). In particular,
without an access code whoever is on your network can use it: this is how it works, and it
says so.
